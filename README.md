# CutoffAI — MHT CET College Predictor

**MERN Stack Edition** | Predicts 2025 college admission cutoffs using AI trained on 3 years of real MHT CET data (2022–2024).

**Model Accuracy:** MAE 0.83 percentile points, R² 0.9983  
**Tech Stack:** MongoDB · Express · React · Node.js + Python ML Backend

> 🎯 **Quick Start:** See [MERN_CONVERSION_GUIDE.md](MERN_CONVERSION_GUIDE.md) for setup instructions

---

## 📋 Features

✅ **315+ Colleges** - Complete coverage of all engineering colleges in Maharashtra  
✅ **AI-Powered** - XGBoost model trained on 87K real data points  
✅ **Instant Results** - Predictions in under 1 second  
✅ **Safe/Moderate/Reach Classification** - Personalized chance analysis  
✅ **3-Year Cutoff Trends** - Historical data visualization  
✅ **100% Free & Private** - No signup, no data storage

## Setup & Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the full training pipeline (once)
```bash
python scripts/run_pipeline.py
```
This runs Phase 1 → 2 → 3 and generates all files in `data/processed/`.

### 3. Start the API
```bash
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

### 4. View interactive API docs
```
http://localhost:8000/docs
```

## API Endpoints

### POST `/api/predict/colleges`
Main prediction — returns colleges a student can get.

**Request body:**
```json
{
  "score": 85.5,
  "category": "GOPENS",
  "seat_type": "State Level",
  "branch_names": ["Computer Engineering", "Information Technology"],
  "include_reach": true,
  "top_n": 50
}
```

**Response:**
```json
{
  "total": 23,
  "user_score": 85.5,
  "category": "GOPENS",
  "seat_type": "State Level",
  "colleges": [
    {
      "college_id": 1234,
      "college_name": "College of Engineering, Pune",
      "branch_name": "Computer Engineering",
      "predicted_cutoff_2025": 82.4,
      "score_2022": 78.1,
      "score_2023": 80.5,
      "score_2024": 82.0,
      "chance": {
        "label": "Safe",
        "color": "green",
        "desc": "Your score is well above cutoff",
        "gap": 3.1
      }
    }
  ]
}
```

---

### POST `/api/predict/chances`
Check chances for one specific college + branch.

```json
{
  "score": 85.5,
  "college_id": 1002,
  "branch_id": "100219110",
  "category": "GOPENS",
  "seat_type": "State Level"
}
```

---

### GET `/api/filters/all`
Returns all dropdown data in one call (use on app load).

```json
{
  "branches": ["Computer Engineering", "Information Technology", ...],
  "categories": ["GOPENS", "GSCS", "LSCS", ...],
  "category_groups": ["OPEN", "SC", "ST", "OBC", ...],
  "seat_types": ["State Level", "Home University", ...]
}
```

---

### GET `/api/colleges/`
List all colleges. Supports `?search=pune` and `?status=Government`.

### GET `/api/colleges/{college_id}/history`
Year-by-year cutoffs + 2025 prediction. Supports `?branch_id=...`.

### GET `/api/health`
Returns model status and accuracy metrics.

## Chance Labels

| Label | Color | Meaning |
|-------|-------|---------|
| Safe | 🟢 green | Score ≥ cutoff + 5 |
| Moderate | 🟡 yellow | Score within 0–5 above cutoff |
| Reach | 🟠 orange | Score within 3 below cutoff |
| Unlikely | 🔴 red | Score > 3 below cutoff |

## Updating with New Year Data (e.g. 2025 actuals)
1. Add `2025.xlsx` to `data/raw/`
2. Update year list in `phase1_data_prep/merge_and_clean.py`
3. Re-run `python scripts/run_pipeline.py`
4. Restart the API — new model auto-loads
